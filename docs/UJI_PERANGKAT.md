# Membuktikan Android 12 fisik

Semua langkah berikut belum dijalankan di sesi cloud. Catat vendor/model alias, Android/API, versi Chrome/APK, hash artifact, fingerprint public key (jangan key privat), UTC start/duration, expected/observed dan evidence yang aman. Pakai format brief verification/03_FORMAT_BUKTI.md; jangan mengubah NOT_RUN menjadi PASS tanpa hasil.

1. **G1:** clean install tanpa Termux/root/helper, pair manual di APK/popup, connect TLS, buka Chrome. Tutup Activity lalu reopen tanpa pairing. Restart Wireless Debugging sampai port connect berubah; buktikan NSD self-device dan reconnect dalam target 60 detik tanpa key baru selama trust valid. Uji key revoke, debug off, Wi-Fi berubah/stale service, network tanpa mDNS. Kunci public fingerprint tetap, peer pin valid. Jika pin certificate pairing/connect berbeda, investigasi protokol; jangan trust-all connect.
2. **G2:** client MCP target devices/select_device/status/tabs/open/switch/read/navigate/back/reload/click/type/scroll/close/screenshot pada Chrome yang terpasang dan profil test. Verifikasi screenshot decoded dimensions/MIME, fresh timestamp, hasil ditampilkan client. Lindungi tab pengendali. Screenshot setelah reload/tab switch dan timeout; status/read tetap pulih dalam target 15 detik bila Chrome tersedia.
3. **G3/G4:** izinkan/deny overlay; drag/collapse/close; Settings security screens; Activity dismissed; notifikasi Jeda/Lanjut/Stop. Jeda menolak aksi, Stop benar-benar menutup sockets/service/notifikasi. Force-stop tidak bypass. Screen off/lock/unlock, reboot, restrictions vendor, intent/key/deviceId/config persistence. Build dua versionCode dengan owner signature sama untuk update; jangan reset storage untuk membuat test lulus.
4. **G5:** minimum 60 menit: 15 browsing tanpa capture, 15 screenshot-only, 30 campuran/interupsi. Catat tiap lapisan, heap, queue, latency, generation dan recovery. Wi-Fi/debug/port changes, screenshot timeout/oversize, lock/unlock, close overlay/Activity. Jangan retry ambiguous mutations. Soak 8–24 jam terpisah, belum diuji.
5. **G6:** dua ponsel nyata; scope salah, revoke salah target, satu disconnect tanpa mengganggu yang lain, stale response/reconnect race, duplicate payload conflict, command queued expired, UNKNOWN. Backend harness hanya mendukung bukti logika isolasi awal.
6. **G7/G8/G9:** fresh account config deployment HTTPS, OAuth/resource/state/PKCE/scopes/refresh/revoke, user-facing client, release key owner, ZIP fresh unzip → build → enroll/pair. Scan private material dan signer; catat limits Cloudflare yang benar-benar diukur.

Runner `tests/device-soak.mjs` tersedia untuk read/screenshot+status 60 menit. Set BRIDGE_MCP_URL, BRIDGE_MCP_ACCESS_TOKEN, BRIDGE_DEVICE_ID, BRIDGE_TAB_ID securely serta BRIDGE_PHYSICAL_FIXTURE=ANDROID_12_OWNER_AUTHORIZED. Runner tidak merekam konten atau tokens. Ia tidak otomatis membuktikan perangkat fisik, gangguan manual, overlay atau seluruh G5; hasil tanpa failure tetap UNCERTAIN sampai evidence owner/device ditambahkan. Command mutasi diberi prosedur manual agar tidak otomatis retry tindakan ambigu.
