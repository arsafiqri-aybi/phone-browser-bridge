Bangun Phone Browser Bridge dari nol menggunakan seluruh brief lokal dalam folder Phone_Browser_Codex_Prompt_Pack. Baca 00_MULAI_DI_SINI.md, 01_PROMPT_UTAMA_CODEX.md, AGENTS.md, lalu semua file spec/, workflow/, context/, verification/, sources/, dan templates/ yang relevan sebelum membuat kode.

Paket ini adalah konteks lengkap; jangan mengandalkan chat sebelumnya atau mengkloning proyek lama. Target Android 12, satu aplikasi tanpa Termux, pairing ADB awal manual dan reconnect otomatis dengan discovery port, layanan background dengan izin pemilik, popup overlay, Chrome asli di ponsel, serta MCP Cloudflare untuk beberapa perangkat yang terisolasi. iOS ditunda.

Laksanakan pembangunan, bukan hanya menjawab dengan rencana atau contoh kode. Dahulukan pembuktian embedded ADB pairing + reconnect pada Android 12 sebelum membangun semua UI. Hasil akhir harus mencakup source lengkap, APK dengan status signing yang jelas, bundel deployment Cloudflare, tutorial Indonesia, dan bukti pengujian, dikemas dalam satu ZIP hasil. Terapkan seluruh gate dan batas keamanan dalam brief. Jangan mengklaim PASS atau aman tersertifikasi tanpa bukti. Jika alat, kredensial, signing key, atau perangkat fisik belum tersedia, selesaikan pekerjaan yang memungkinkan dan tandai bagian tersebut secara tepat, disertai langkah konkret pemilik untuk melanjutkan.
