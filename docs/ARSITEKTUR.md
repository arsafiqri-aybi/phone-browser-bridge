# Arsitektur dan protokol

Client MCP → HTTPS Worker → device Durable Object → WSS outbound APK → agent native Java → ADB TLS loopback → socket Chrome DevTools. Tidak ada inbound tunnel internet ke ponsel. TCP proxy sementara bind 127.0.0.1 dan hanya membuka ADB `localabstract:chrome_devtools_remote`; tidak ada remote shell. Tidak ada WebView yang menggantikan profil Chrome.

Registry SQLite menyimpan hash credential, enrollment, OAuth clients/codes/refresh, device owner/scopes/revocation dan MCP sessions terikat credential. DeviceRelay SQLite menyimpan connection generation, health metadata dan journal mutasi. Nama DO memakai installationId/deviceId. Server menentukan identitas dari auth, bukan deviceId dalam payload. Sesi memilih device secara eksplisit, termasuk device offline; pemilihan tidak dipindah otomatis.

Envelope v1: installationId, deviceId, connectionGeneration, requestId, actionId untuk mutasi, SHA256 dari canonical JSON `{method,payload}`, method, deadlineAt UTC, payload. Sorting keys dan escaping diuji lintas Java/JS. Response mengorelasikan request/digest/generation dan status DONE/ERROR/UNKNOWN. Journal disimpan sebelum side effect pada server dan APK. Action ID yang sama + payload sama mengembalikan receipt; beda payload ACTION_CONFLICT. Disconnect/deadline sesudah dispatch memberi UNKNOWN dan tidak memutar ulang. Restart menandai receipt DISPATCHED sebagai UNKNOWN. Tombstone tidak dihapus: kapasitas 10.000 memberi JOURNAL_FULL alih-alih menerima replay lama. Receipt tidak menyimpan page text atau screenshot.

Control/heartbeat 5 detik berjalan terpisah dari supervisor recovery, antrean aksi (1 concurrency, 4 queued), screenshot (1 concurrency, 1 queued), probe Chrome, dan CDP session capture. Relay pending maksimal 6. Tidak ada session timer buatan. Deadline 20 detik pada server meliputi transport, antrean, execution dan respons. Device menolak expired atau old generation sebelum dispatch. CDP pending dibersihkan pada timeout/close; capture memiliki client/socket sendiri. Latency/heap/status metadata tidak memasukkan halaman, URL login atau exception mentah.

Foreground service dimulai tindakan user terlihat, memakai connectedDevice type dan notifikasi. Owner intent persisted active/paused/stopped terpisah dari health. START_STICKY tidak menjamin OS akan restart. Activity/popup dismissed tidak sama dengan Stop. Tidak ada boot receiver yang diam-diam menghidupkan service, atau wake lock permanen. Setelah reboot/force-stop, owner mungkin perlu tap Lanjut. Lockscreen ditolak untuk browser commands; screenshot unavailable tidak berarti owner stopped.

Status per layer mencantumkan state, checkedAt, lastSuccessAt, reasonCode, connectionGeneration. Metadata >20 detik menjadi unknown; relay heartbeat >15 detik membuat device offline. Healthy relay tidak memalsukan ADB/Chrome healthy. Peer trust lokal dipin setelah PAKE dengan TLS exporter; key privat AES-GCM dibungkus Android Keystore, backup aplikasi dimatikan. ADB pin terhadap public key server harus diverifikasi pada Android fisik G1.
